# Османская история — PWA-прототип

Это первый технический прототип адаптивной браузерной игры с возможностью установки как PWA.

## Что уже работает
- Адаптивный интерфейс для телефона и компьютера.
- Главное меню и переходы между разделами.
- Форма создания героини и выбор даты.
- Начальная игровая сцена с тремя вариантами действий.
- Завершение дня, переход календаря и дневник.
- Локальное сохранение в браузере.
- Настройки беременности и распространения болезней (пока только сохраняют переключатели).
- Манифест и service worker для установки и базовой офлайн-оболочки.

## Что пока является заглушкой
- ИИ не подключён: тексты событий демонстрационные.
- Генерация портретов и иллюстраций не подключена.
- Карта дворца, NPC, отношения, родословные, экономика и медицинская система ещё не реализованы.
- Сохранения пока локальные и не синхронизируются между устройствами.

## Запуск
PWA требует HTTPS или localhost. Для локального тестирования можно запустить любой статический сервер в папке проекта, например:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

Для установки на телефон/компьютер проект нужно разместить на HTTPS-хостинге. После этого браузер предложит установку, если устройство и браузер поддерживают PWA.
