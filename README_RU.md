# Дворцовая жизнь — версия 3

Обновление включает:
- выбор даты начала через прокручиваемые списки дня, месяца и года;
- ровно три сюжетных решения за игровой день;
- подробный текст событий и итоговый отчёт после третьего решения;
- переход к следующему дню только по кнопке;
- дневник, сохраняющийся в браузере на этом устройстве.

Это автономный прототип с заранее написанными событиями, не подключённая генеративная ИИ-система. Для публикации замените файлы в корне репозитория GitHub Pages.
