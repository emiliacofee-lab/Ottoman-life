# Дворцовая жизнь v4
Обновлённый интерфейс с вкладками, созданием персонажа и выбором внешности, датой с 1299 года, семью сценами от рассвета до ночи, возможностью читать сцену и продолжать, дневником, показателями и сохранением в браузере.

Сюжет пока локальный, не подключён к генеративному ИИ. Замените содержимое репозитория файлами из архива.
